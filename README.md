# Asymmetric Update Governance (AUG) (possibly coined term)

An experimental multi-agent reasoning protocol that uses asymmetric critique and revision. This project evaluates AUG against a conventional Multi-Agent Debate (MAD) approach.

## Research Question

Can a smaller number of model interactions produce reasoning that is comparable to or better than conventional multi-agent debate?
